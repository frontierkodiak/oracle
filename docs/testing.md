# Testing quickstart

- Unit/type tests: `pnpm test` (Vitest) and `pnpm run check` (typecheck).
- Gemini unit/regression: `pnpm vitest run tests/gemini.test.ts tests/gemini-web`.
- Browser smokes: `pnpm test:browser` (builds, checks DevTools port 45871, then runs `scripts/browser-smoke.sh`, which sends real prompts to ChatGPT). The smoke script refuses to run unless `ORACLE_LIVE_TEST=1` and an explicit `ORACLE_BROWSER_SMOKE_FAST_MODEL` are set. The fast model must be `gpt-5.5-instant` (trimmed, case-insensitive; anything else is refused): Instant has no Pro effort tier, whereas a Thinking model can keep a Pro effort persisted in the ChatGPT picker if effort selection fails, and Oracle has no fail-closed mode for non-Pro effort. Every leg passes `--browser-model-strategy select`; a saved `browser.thinkingTime: pro` aborts on Instant instead of submitting. The Pro legs (markdown check and reattach flow) are skipped unless `ORACLE_BROWSER_SMOKE_PRO_MODEL` names a Pro model; each Pro leg spends a Pro message from the account allowance, so never enable them for bridge/capture/transport testing. `scripts/browser-smoke-upload-only.sh` has the same `ORACLE_LIVE_TEST=1` and explicit non-Pro fast-model requirements. Requires a signed-in Chrome profile; runs headful but hides the window by default unless Chrome forces focus.
- Browser live suites (`tests/live/browser-*.test.ts`, via `pnpm test:live`) use `GPT-5.5 Instant` (no Pro effort tier). Their Pro cases run only when `ORACLE_LIVE_BROWSER_PRO_MODEL` names the Pro model explicitly; otherwise they log a skip.
- Live API smokes: `ORACLE_LIVE_TEST=1 OPENAI_API_KEY=… pnpm test:live` (excludes OpenAI pro), `ORACLE_LIVE_TEST=1 OPENAI_API_KEY=… pnpm test:pro` (OpenAI pro live). Expect real usage/cost.
- Gemini web (cookie) live smoke: `ORACLE_LIVE_TEST=1 pnpm vitest run tests/live/gemini-web-live.test.ts` (requires a signed-in Chrome profile at `gemini.google.com`).
- MCP focused: `pnpm test:mcp` (builds then stdio smoke via mcporter).
- If browser DevTools is blocked on WSL, allow the chosen port (`ORACLE_BROWSER_PORT`/`ORACLE_BROWSER_DEBUG_PORT`, defaults to 45871); see `scripts/test-browser.ts` output for firewall hints.
