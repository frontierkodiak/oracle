# Testing quickstart

- Unit/type tests: `pnpm test` (Vitest) and `pnpm run check` (typecheck).
- Gemini unit/regression: `pnpm vitest run tests/gemini.test.ts tests/gemini-web`.
- Browser smokes: `pnpm test:browser` (builds, checks DevTools port 45871, then runs `scripts/browser-smoke.sh`, which sends real prompts to ChatGPT). The smoke script refuses to run unless `ORACLE_LIVE_TEST=1` and an explicit non-Pro `ORACLE_BROWSER_SMOKE_FAST_MODEL` (e.g. `gpt-5.5`) are set. The fast model must be one of `gpt-5.5`, `gpt-5.5-instant`, `gpt-5.4` (case/whitespace trimmed; anything else is refused). Every leg passes `--browser-model-strategy select`, and fast legs pass an explicit `--browser-thinking-time` (`standard`, or `light` for Instant), so a saved `~/.oracle/config.json` cannot select Pro. The Pro legs (markdown check and reattach flow) are skipped unless `ORACLE_BROWSER_SMOKE_PRO_MODEL` names a Pro model; each Pro leg spends a Pro message from the account allowance, so never enable them for bridge/capture/transport testing. `scripts/browser-smoke-upload-only.sh` has the same `ORACLE_LIVE_TEST=1` and explicit non-Pro fast-model requirements. Requires a signed-in Chrome profile; runs headful but hides the window by default unless Chrome forces focus.
- Browser live suites (`tests/live/browser-*.test.ts`, via `pnpm test:live`) use explicit non-Pro models (GPT-5.5 Instant, or Thinking 5.5 with `standard` effort). Their Pro cases run only when `ORACLE_LIVE_BROWSER_PRO_MODEL` names the Pro model explicitly; otherwise they log a skip.
- Live API smokes: `ORACLE_LIVE_TEST=1 OPENAI_API_KEY=… pnpm test:live` (excludes OpenAI pro), `ORACLE_LIVE_TEST=1 OPENAI_API_KEY=… pnpm test:pro` (OpenAI pro live). Expect real usage/cost.
- Gemini web (cookie) live smoke: `ORACLE_LIVE_TEST=1 pnpm vitest run tests/live/gemini-web-live.test.ts` (requires a signed-in Chrome profile at `gemini.google.com`).
- MCP focused: `pnpm test:mcp` (builds then stdio smoke via mcporter).
- If browser DevTools is blocked on WSL, allow the chosen port (`ORACLE_BROWSER_PORT`/`ORACLE_BROWSER_DEBUG_PORT`, defaults to 45871); see `scripts/test-browser.ts` output for firewall hints.
